ShopNow - Boutique en ligne

 Description

ShopNow est une landing page responsive pour une boutique en ligne.
L'objectif est de présenter les produits de manière simple, moderne et attractive.

CONCEPTION

J'ai utilisé HTML5 et CSS3 pour créer la page.

Le design utilise principalement des couleurs sombres avec une couleur orange
pour mettre en valeur les éléments importants.

La page est responsive afin de s'adapter aux ordinateurs, tablettes et
appareils mobiles.

J'ai également utilisé des cartes produits pour présenter clairement
les catégories, descriptions, prix et boutons d'achat.

FONCTIONNALITE

- Barre de navigation
- Section d'accueil
- Présentation des produits
- Section À propos
- Section Contact
- Design responsive pour mobile
- Animations au survol des boutons et produits
